## Визуал и взаимодействия

- [x] Тёмная визитка, квадратная геометрия, фон из GIF и переданный аватар.
- [x] Вступительный экран содержит только часы и логотип STOPCO; нажатие на экран открывает карточку и запускает музыку.
- [x] Логотип вращается и меняет цвета; при reduced motion анимация отключена.
- [x] Надпись «НЕСКУЧНАЯ ЧАСТЬ ИНТЕРНЕТА» и видимая кнопка входа удалены.
- [x] После нажатия экран уходит вверх, часы и логотип растворяются, появляется короткий эффект сканирующих полос; музыка запускается сразу.
- [x] Добавлены подсветка контактов, терминальный мигающий знак и подсветка за указателем; hover декоративных элементов убран.
- [x] Добавлены белые полупрозрачные Neural Glow волны поверх фонового изображения; эффект реагирует на указатель и учитывает reduced motion.
- [x] Добавлен чёрно-белый пружинный след за курсором, отключаемый для touch и reduced motion.
- [x] Убраны подписи «ЛИЧНАЯ СТРАНИЦА / НЕПРИЧЁСАННЫЙ ИНТЕРНЕТ» и SYSTEM ONLINE; добавлены последовательное появление блоков, анимация обложки, стрелок и аватара.
- [x] На устройствах с мышью реализован квадратный курсор: движение, деформация и притяжение к ссылкам и кнопкам.
- [x] Курсор вынесен поверх страницы: белый квадрат инвертирует содержимое и притягивается к интерактивным элементам с пружинным вылетом.
- [x] Подобраны широкий Unbounded для имени, IBM Plex Mono для интерфейса и пиксельный Press Start 2P для коротких англоязычных подписей.
- [x] При `prefers-reduced-motion` и на touch-устройствах используется системный курсор без кастомной анимации.
- [ ] Уточнить по визуальной оценке AL-S, насколько пластика и ощущение курсора соответствуют задуманному примеру; текущая реализация проверена технически, но дизайн ещё не утверждён.
- [x] Доработать визуал: читаемость подписей, компактная мобильная сетка контактов, квадратный курсор с пружинной деформацией.
- [x] Просмотрены галереи Codrops и Style Gallery; тяжёлые эффекты отложены, чтобы не перегружать карточку.
