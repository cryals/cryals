# STOPCO Secure Tablet — дизайн-система

Единая дизайн-система для сайта STOPCO Secure Tablet. Интерфейс должен ощущаться как защищённый промышленный терминал: строгий, технический, малошумный и рассчитанный на работу в условиях ограниченного визуального внимания.

## 1. Визуальное направление

- Основа композиции — почти абсолютная темнота, большие поля пустого пространства и редкие, точно выровненные элементы.
- Терминальный голос создают префиксы `>`, текст в верхнем регистре, моноширинный шрифт, положительный трекинг и последовательность загрузки/печати.
- Глубина создаётся цветом поверхностей, тонкими границами и расстояниями. Не использовать глянцевые эффекты, размытие, тяжёлые тени или декоративные градиенты.
- Вся форма прямоугольная и инженерная. Базовый режим использует `border-radius: 0`; небольшие радиусы из alpha-токенов допустимы только для специальных компонентов, если это явно нужно интерфейсу.
- Цветовая система монохромная. Красный `#FF5A5F` зарезервирован исключительно для ошибки, критического предупреждения или деструктивного действия.

## 3. Типографика

### Роли шрифтов

- `Inter` — заголовки, структурные подписи, элементы управления и длинные читаемые фрагменты.
- `JetBrains Mono` — навигация, кнопки терминального типа, body/status copy, системные сообщения, код и boot-sequence.
- Fallback: `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` для Inter и `'Courier New', Courier, monospace` для JetBrains Mono.

## 4. Размеры, сетка и responsive

Базовый шаг — `8px`.

| Токен | Значение | Использование |
| --- | --- | --- |
| `xs` | `8px` | Иконки и плотные inline-отступы |
| `sm` | `16px` | Внутренние отступы и промежутки списков |
| `md` | `24px` | Паддинг карточек и подзоны секций |
| `lg` | `32px` | Средний вертикальный ритм |
| `xl` | `48px` | Разделители блоков и расстояние от заголовка до контента |
| `section` | `88px` | Вертикальный отступ крупных секций |
| `band` | `100px` | Полноширинная hero-полоса |

Сетка одноколоночная на всех размерах. Ширина контента и горизонтальный отступ секции:

| Ширина viewport | Ширина контента | Отступ по X | Размер display |
| --- | --- | --- | --- |
| `375px` | `343px` | `28px` | `46px` |
| `768px` | `734px` | `38px` | `61px` |
| `1024px` | `990px` | `51px` | `82px` |

Использовать fluid CSS через `clamp()` или эти пять контрольных точек. Навигация остаётся горизонтальной; hamburger-меню не вводить без отдельного решения. Высота любого tappable-элемента — минимум `42px`.

## 5. Формы и компоненты

### Кнопки

Основная кнопка:

```css
background: #0A0A0A;
color: #F4F4F2;
border: 1px solid #555552;
border-radius: 0;
height: 42px;
padding: 0 16px;
font: 500 11px/normal 'JetBrains Mono', monospace;
letter-spacing: 0.88px;
text-transform: uppercase;
box-shadow: none;
```

На hover: `background: #20201F`, `border-color: #EEEEEE`. На `:focus-visible`: `outline: 2px solid #FFFFFF`.

Дополнительные варианты из alpha-токенов:

- secondary: прозрачный фон, светлая граница и светлый текст, высота `40–42px`;
- link: без границы и фона, без радиуса, только для inline-навигации;
- не делать кнопки чрезмерно округлыми, крупными или декоративными.

### Карточки и панели

По умолчанию: `background: rgba(14, 14, 14, 0.92)`, `border: 1px solid #323230`, `padding: 24px`, `box-shadow: none`. Рекомендуемый радиус — `0`; alpha-вариант `8px` допустим только для явно обозначенной карточной поверхности, если это не разрушает терминальный характер.

Hover карточки: `transform: translateY(-2px)` и `border-color: #E8E8E5`.

### Поля и чипы

- input: тёмный фон, светлый текст, JetBrains Mono, минимум `40px` высоты, `8px 16px` внутреннего отступа, тонкая граница;
- chip: компактная статусная метка с `4px 10px` padding и pill-формой только там, где это действительно обозначает компактный статус;
- tooltip: графитовая поверхность `#374151`, светлый текст, `8px 12px` padding, без декоративных эффектов.

### Навигация и футер

Навигация: прозрачный фон, `JetBrains Mono`, `9px`, `letter-spacing: 0.5px`, цвет `#969694`, верхний регистр. На hover — `#FFFFFF`; область нажатия должна достигать минимум `42px` по высоте.

Футер: `rgba(5, 5, 5, 0.9)`, граница `1px solid #20201F`, высота около `77px`, Inter, светлый текст, без тени.

### Hero и boot-sequence

Hero может получать только декоративный тёмный overlay:

```css
background: linear-gradient(135deg, rgba(22, 22, 22, 0.82), rgba(9, 9, 9, 0.92));
```

Overlay не использовать поверх светлого контента. Анимация печати строк вида `> INITIALIZING...` является характерной, но конкретные timing/easing пока не зафиксированы — выбирать сдержанные значения без отвлекающей motion-нагрузки.

## 6. Слои и состояния

Глубина строится без теней: `#030303` → `#0A0A0A` → карточная поверхность → футер. Использовать только границы `1px`; более толстые штрихи не являются частью системы.

- disabled: `opacity: 0.5`;
- button `:focus-visible`: `outline: 2px solid #FFFFFF`;
- прочие focusable-элементы: `outline: 1px solid #FFFFFF`;
- error/destructive: `#FF5A5F`, только когда нужно явно сообщить об ошибке или опасном действии;
- dropdown: предполагаемый `z-index: 10`;
- sticky: предполагаемый `z-index: 100`.

## 7. Правила использования

### Делать

- сохранять чёрный холст, высокую контрастность и большие зоны воздуха;
- использовать Inter для заголовков/структуры и JetBrains Mono для системного голоса;
- применять верхний регистр и положительный трекинг к терминальным label-элементам;
- держать компоненты плоскими, точными и ограниченными одной пиксельной границей;
- масштабировать display от `46px` до `104px` по responsive-лестнице.

### Не делать

- не добавлять случайные цветные акценты, градиенты, glassmorphism и тяжёлые тени;
- не использовать радиусы больше необходимых для явно согласованных alpha-компонентов;
- не смешивать Inter с терминальными кнопками, навигацией и boot-строками;
- не убирать положительный трекинг у моноширинного micro-type `7–11px`;
- не строить многоколоночный layout и не заполнять пустое пространство декоративным шумом;
- не добавлять error/success/warning ramp без отдельной спецификации.

## 8. Ограничения и незафиксированные зоны

Документ объединяет измеренную terminal-поверхность и alpha-токены Stopco Secure Tablet. При конфликте приоритет у измеренных правил terminal-поверхности: `0px` radius, отсутствие теней, одноколоночный layout и строгая монохромность. Alpha-значения для радиусов, input, chip, tooltip и error служат расширением для будущих экранов и применяются только по необходимости.

Пока отдельно не определены: полноценные dashboard/login-поверхности, modal/drawer, точные active/pressed/loading/skeleton-состояния, библиотека иконок, timing анимаций, стиль dropdown/sticky-элементов и light mode. Не изобретать их произвольно — сначала дополнить эту спецификацию.
